eXtensible Exchange Template (XET)

Szablony XML wg XSD, kolejka komunikacji i integracja z KSeF 2.0 dla Odoo 15

Opis

Moduł mapuje pola modeli Odoo na strukturę XML opisaną schematem XSD (szablony XET) i generuje dokument XML. Każda operacja wymiany jest zapisywana jako rekord communication.log i przekazywana do dostawcy (providera).

Provider KSeF wysyła faktury do Krajowego Systemu e-Faktur 2.0, pobiera UPO, importuje faktury zakupowe, obsługuje tryb offline i kody QR. Provider LocalDir zapisuje pliki w katalogu serwera.

Funkcje

XET
  • szablon z drzewem węzłów, przestrzeniami nazw i typami XSD
  • tworzenie szablonu z XSD, import i eksport JSON
  • generowanie XML i walidacja faktury wg XSD
Komunikacja
  • providery ksef i localdir
  • log operacji ze stanem i krokami
  • kolejka przetwarzana przez zadanie cykliczne
KSeF 2.0
  • wysyłka faktury, status, UPO
  • import faktur zakupowych
  • tryb offline, QR, podgląd faktury z XML
  • backend python lub klient Java

Jak to działa

  1. Walidacja – faktura sprawdzana względem XSD szablonu.
  2. Zatwierdź wysłanie – XML generowany z szablonu, log w stanie queued.
  3. Kolejka – zadanie cykliczne wykonuje kroki: auth, open_session, send_invoice, check_status, download_upo, close_session.
  4. Import – zadanie cykliczne tworzy log listy; dla nowych faktur powstają logi potomne, które pobierają XML i tworzą fakturę zakupową.

Konfiguracja

  1. Provider KSeF – środowisko, adres API, autoryzacja, backend, parametry importu.
  2. Certyfikaty – kreator importu certyfikatów, pobranie kluczy publicznych MF.
  3. Dostawcy Usług – provider typu ksef z wybraną konfiguracją.
  4. Szablony – szablon XET z providerem, przypisany do faktury.
  5. Zadania cykliczne – włączenie zadań KSeF (domyślnie nieaktywne).
