Przegląd modułu

Moduł hfb_xmlmap_exporter – XET, komunikacja i KSeF dla Odoo 15.

Przeznaczenie

Moduł ma trzy warstwy. XET (eXtensible Exchange Template) mapuje pola modeli Odoo na strukturę XML opisaną schematem XSD i generuje dokument XML. Warstwa komunikacji rejestruje każdą operację wymiany jako rekord communication.log i przekazuje ją do dostawcy (providera). Provider KSeF realizuje wysyłkę faktur do KSeF 2.0, pobieranie UPO, import faktur zakupowych, tryb offline i kody QR. Drugi provider, LocalDir, zapisuje pliki w katalogu serwera.
